# Sprint 7 — API-тестирование сервиса Яндекс Самокат

## Описание проекта

Проект содержит автотесты API сервиса Яндекс Самокат.

В рамках проекта проверяются основные возможности API:
- создание курьера;
- авторизация курьера;
- создание заказа;
- получение списка заказов.

## Используемые технологии

- Python
- Pytest
- Requests
- Allure

## Установка зависимостей

Установить необходимые библиотеки:

```bash
pip install -r requirements.txt
```

## Запуск автотестов

Запустить все тесты:

```bash
python -m pytest -v
```

## Создание Allure-отчёта

Запустить тесты с сохранением результатов:

```bash
python -m pytest --alluredir=allure-results
```

Сформировать HTML-отчёт:

```bash
allure generate allure-results --clean -o allure-report
```

Открыть отчёт:

```bash
allure open allure-report
```
